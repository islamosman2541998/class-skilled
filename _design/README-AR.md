# طريقة الاستخدام مع Claude Code في VS Code

## 1. التجهيز (مرة واحدة)
1. فك الضغط داخل `C:\laragon\www\` بحيث يبقى عندك:
   ```
   C:\laragon\www\class-skilled\
     CLAUDE.md          ← قواعد المشروع، Claude Code بيقراه تلقائي في كل جلسة
     _design\
       README-AR.md     ← الملف ده
       PROGRESS.md      ← سجل المراحل، Claude Code بيحدّثه بعد كل مرحلة
       phases\          ← 11 ملف مرحلة (00 إلى 10)
       screens\         ← صور التصميم (الموقع والداشبورد)
       photos\          ← صور الشغل الحقيقية
       brand\           ← اللوجو بنسخه ودليل الهوية
       docs\            ← الرخصة، شهادة التصنيف، البروفايل، الليترهيد
       content\         ← نصوص المحتوى عربي وإنجليزي
   ```
2. شغّل Laragon (Apache أو Nginx + MySQL). اتأكد إن PHP 8.2 أو أحدث.
3. افتح الفولدر `C:\laragon\www\class-skilled` في VS Code، وافتح Claude Code.
4. لو هتضيف صور حقيقية جديدة، حطها في `_design\photos\` قبل المرحلة 01 (الـ seeder بيستوردها من هناك).

## 2. تنفيذ كل مرحلة
- كل مرحلة في جلسة لوحدها. ابدأ كل مرحلة بجلسة جديدة (`/clear`) عشان السياق يبقى نظيف.
- انسخ الرسالة دي والصقها في Claude Code، وغيّر رقم المرحلة واسم الملف:

```
اقرأ CLAUDE.md و _design/PROGRESS.md ثم نفّذ المرحلة الموجودة في الملف
_design/phases/00-setup.md بالكامل.
- اشتغل على المرحلة دي بس، ومتبدأش المرحلة اللي بعدها.
- قبل ما تبدأ اكتبلي خطة مختصرة بالمهام بالترتيب.
- لو فيه قرار مش واضح أو باكدج مش متوافق، وقّف واسألني.
- في الآخر شغّل كل اختبارات الجودة المذكورة، وحدّث PROGRESS.md، واعمل commit، ثم اعرض ملخص بالمنجز وبأي حاجة محتاجة مني.
```

ترتيب الملفات:
```
00-setup.md
01-data-foundation.md
02-dashboard-shell.md
03-media-settings-seo.md
04-content-modules.md
05-menu-builder.md
06-site-layout-home.md
07-site-inner-pages.md
08-forms-requests.md
09-seo-analytics-dashboard-home.md
10-hardening-deploy.md
```

## 3. بعد كل مرحلة
- افتح `http://class-skilled.test` واللوحة على `http://class-skilled.test/cs-panel` وجرّب بنفسك.
- لو فيه ملاحظات، اكتبها في نفس الجلسة قبل ما تنتقل للمرحلة اللي بعدها.
- اتأكد إن الـ commit اتعمل. لو حاجة باظت، ترجع لآخر commit سليم.

## 4. ملاحظات
- **صور التصميم في `screens` مرجع للهيكل والترتيب بس.** القرارات الأحدث مكتوبة في `CLAUDE.md` وهي اللي بتمشي:
  - خطوط أصغر.
  - سلايدر في الهيرو.
  - سلايدرات زجاجية للكروت.
  - أنيميشن في الهوم.
- **المحتوى التجريبي** (أسماء المشاريع، المقالات، مواعيد العمل) معلّم في `content.md` بكلمة sample. ده بيتغير من الداشبورد.
- **رقم الواتساب** في `content.md` محتاج تأكيد من الشركة.
- **الـ seeder التجريبي** (DemoContentSeeder) بيشتغل على اللوكال بس. على السيرفر بيشتغل EssentialSeeder بس.
